## Observed, not inferred

| Measure | Result | Limitation |
|---|---|---|
| Crew confidence before -> after / mean 1-5 | | Self-report; crew-level, not individual assessment |
| Named task duration / median minutes | | Tasks may differ; no causal productivity comparison |
| Passing regression tests / reported count | | Test count is not coverage or quality; inspect selected examples |
| Working customer journeys | | Judge-observed exercise behavior, not production readiness |
| Crew Monday commitments / count | | Intention is not demonstrated adoption |
| Optional customer-approved pilot baseline | | Record collection method, sample, comparability, and missing observations |

The host summarizes confidence means, median task minutes, total reported passing
tests, and observation sample size. Its export includes per-crew practices and
criterion-level evidence notes. Report missing observations explicitly.

## Shareable claims / approval gate

"Crews demonstrated three regression tests" is supportable if observed.
"Copilot increased productivity by 40%" is not established by this event.
Obtain customer permission for names, logos, quotes, photos, and externally shared
results; a registration or completed exercise is not that permission.
